I'm Naivy Pujol Méndez — a software engineer based in Berlin. I build and maintain backend systems with Kubernetes, Go, and Python at Mobilistics, and I study languages on my own time. Both reward the same habit: break a large, messy problem into small pieces someone can actually act on.

At Mobilistics I work on distributed infrastructure and release automation, where reproducibility matters — if it can't be described in code, it can't be trusted. Outside work I'm an active open-source contributor, and NixOS is both my desktop OS and my way of keeping my own machines sane. Studying languages has made me attentive to structure — grammar, patterns, edge cases — which quietly shows up in how I write and review code.
