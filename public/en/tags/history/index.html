    Authoring Redaction History
    Redaction History hugo-brewm supports redaction history for tracking changes to your content over time. Enabling History History is enabled by default. To disable it: [params.posts] disableHistory = true Redaction Syntax Use strikethrough syntax to redact content: ~~This text is redacted~~ This text is visible.
