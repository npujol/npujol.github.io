    Configure Logo and Accent Color
    Logo Configuration The logo can be configured in two ways: as an image mark or as a type-based logo. Image Logo Mark Add the following to your config.toml: [params.logo] logoMark = '/img/logo.svg' logoMarkDark = '/img/logo-dark.svg' Type-based Logo For a text-based logo, set logoType to true: [params.logo] logoType = true This will display the site title as the logo with proper typography.     Discussion Configuration hugo-brewm supports fediverse-based discussion comments.     Configure Pagefind Search
    Pagefind Search Configuration hugo-brewm supports Pagefind for client-side search functionality. Enabling Search Add the following to your config.toml: [params.search] enable = true pagefind = true Building Search Index After building your site, run Pagefind to generate the search index: npx @pagefind/cli --source public Search Fallback When JavaScript is disabled, a fallback search box is shown. You can configure the fallback provider: [params.search] enable = true pagefind = true fallback = 'mojeek' Options for fallback: mojeek — Mojeek search engine duckduckgo — DuckDuckGo (default if not specified) Customizing Search Pagefind automatically indexes your content.     Configure Menu
    Menu Configuration The menu in hugo-brewm is configured through the menus configuration files. You can define menu items in _default/menus.en.toml or similar language-specific files. Example Configuration [[main]] identifier = "home" name = "Home" url = "/" weight = 1 [[main]] identifier = "posts" name = "Posts" url = "/post/" weight = 2 [[main]] identifier = "about" name = "About" url = "/about/" weight = 3 Menu Parameters identifier: Unique identifier for the menu item name: Display name shown in the menu url: URL path the menu item links to weight: Determines the order of menu items (lower = first) pre: Optional icon or prefix post: Optional suffix text Multi-level Menus hugo-brewm supports nested menus through the parent parameter:

    Authoring Fullscreen Content
    Fullscreen Content Fullscreen pages display content without any header, footer, or navigation elements. They occupy the entire viewport. Creating Fullscreen Pages Use type: 'fullscreen' in your frontmatter: --- type: 'fullscreen' title: 'Fullscreen Page Title' --- Your content here. Use Cases Fullscreen pages are ideal for: Presentations — Display content without distractions Showcases — Highlight specific work or projects Articles — Focus readers on the content Gallery pages — Display images without UI elements Fullscreen Example A fullscreen page can contain any valid Markdown or HTML content. The theme ensures the content is properly centered and readable.
