    Configure Logo and Accent Color
    Logo Configuration The logo can be configured in two ways: as an image mark or as a type-based logo. Image Logo Mark Add the following to your config.toml: [params.logo] logoMark = '/img/logo.svg' logoMarkDark = '/img/logo-dark.svg' Type-based Logo For a text-based logo, set logoType to true: [params.logo] logoType = true This will display the site title as the logo with proper typography.
